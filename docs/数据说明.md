# 数据说明

## 仓库里有什么

公开仓库只有通用程序源码、测试、安装和迁移文档及许可证。Release 提供安装包、完整源码包和插件。

你的论文 PDF、笔记、Zotero 数据库、知识库索引、同步基线、冲突副本、聊天记录、账号认证文件、连接令牌和本机路径配置都不会放进仓库。也不要把整份工作目录或 AppData 目录提交到这个软件仓库。

## 本机保存什么

安装后，程序在当前用户的 AppData 中保存配置和同步历史，在所选知识库中写入主笔记、配对索引、图片和必要的冲突副本。每台电脑首次配置时会生成自己的连接令牌。

默认研究分类包括 Agent 长期记忆、上下文管理、数学推理与强化学习、知识蒸馏与模型压缩及待分类。它们只是公开默认项，不包含个人论文清单。可以在本机 `categories` 配置中调整；重新运行安装助手会恢复内置默认项。

## 哪些内容会发给模型

自动分类会把论文标题和摘要交给本机登录的 Codex。

使用 Codex 侧栏提问或主动请求全文时，选中文字、论文片段或工具读取结果可能发送给当前 Codex 服务，具体以你发起的请求和侧栏实现为准。PaperBridge 自己不提供云端笔记服务。

DeepSeek 模式直接请求 `https://api.deepseek.com/chat/completions`。发送问题时，会带上当前问题、这篇论文近期的 DeepSeek 对话，以及你勾选的文献参考资料。默认不发送 PDF 全文，也不自动发送“我的笔记”。连接检查只调用模型列表接口。

论文、PDF、批注和笔记中的文字都只是资料，不代表操作授权。Codex 的记录工具只能追加 AI 整理区，不能写入“我的笔记”。DeepSeek 模式不执行命令或自行写文件，保存回答需要你点击按钮。

## Key 和聊天记录

DeepSeek Key 加密保存在本机状态目录的 `deepseek-secret.json` 中。模式配置单独保存在 `provider-settings.json`，对话按论文保存在 `deepseek-chats` 中。

这些文件都不在知识库里，也不会随源码或安装包发布。加密文件依赖当前 Zotero 资料目录的解密能力，不能直接复制到另一台电脑使用。

## 其他

开源依赖保留上游许可证。安装包暂未使用开发者代码签名证书，本项目也未做完整的第三方安全审计。
