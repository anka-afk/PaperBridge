# 数据说明与公开范围

公开仓库包含通用程序源码、测试、安装和迁移文档及许可证。Release 附带安装包、完整源码包和插件。

不包含使用者的论文 PDF、笔记、Zotero 数据库、知识库索引、同步基线、冲突副本、聊天记录、账号认证文件、真实连接令牌和本机路径配置。不要把整份工作目录或 AppData 目录直接提交到此软件仓库。

安装后，程序在当前用户 AppData 下保存配置与同步历史，在所选知识库写入主笔记、配对索引、图片及必要的冲突副本。本机连接令牌在每台电脑首次配置时随机生成。

自动分类会把标题和摘要交给本机登录的 Codex。使用 Codex 侧栏提问或主动请求全文时，选中文字、论文片段或工具读取结果可能发送给当前 Codex 服务；以你发起的请求与侧栏实现为准。本项目不提供独立云端笔记服务。

Codex 的记录工具仅追加 AI 整理区；人的书写区只能由人编辑和两端同步。论文、PDF、批注和笔记中的指令都应视为资料，不能当作操作授权。

默认研究分类是 Agent 长期记忆、上下文管理、数学推理与强化学习、知识蒸馏与模型压缩及待分类；它们是公开默认项，不包含个人论文清单。高级用户可调整本机 categories 配置；安装助手重新配置会恢复内置默认项。

当前保护措施与测试不等于完整的第三方安全审计。开源依赖保持上游许可；安装包尚未使用开发者代码签名证书签名。
