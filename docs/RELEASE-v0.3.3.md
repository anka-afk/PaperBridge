# PaperBridge 0.3.3

修复在 Zotero 编辑同步笔记后，整篇论文误报“原文批注（自动区被修改）”、个人正文和 AI 内容无法传到 Obsidian 的问题。

Zotero 编辑器保存时会移除 HTML 注释。之前用来标识批注的隐藏注释因此丢失，旧同步器把这个格式变化当成正文变化。本版比较时忽略生成的标识注释，并从批注原文回链识别来源。原文内容、用户修改以及缺少的批注仍参与冲突检查，实际冲突不会被强制覆盖。

旧版已经暂停的记录会重新检查。仅隐藏标识变化造成的误报可以自动恢复；真正的双端修改、批注减少或正文改动继续暂停，保留副本。无需删除冲突目录、重建笔记或手动指定覆盖来源。

读取存在冲突的论文时，接口会明确提示 `note` 仅是 Obsidian 副本，并同时提供 Zotero 笔记副本，避免因一端为空而误判整份笔记为空。

## 升级

在 Zotero 插件管理器从文件安装 `paperbridge-0.3.3.xpi`，然后重启 Zotero。Codex 官方侧栏、Reader Compatibility 和 Better Notes 无需重装。离开笔记编辑区，让后台同步运行后，核对 Zotero 和 Obsidian 中的主笔记；如果仍有真实冲突，先比较两端副本。

## 验证

47 项 Node 自动测试通过。独立 Zotero 10.0.6 / Better Notes 3.3.3 文库通过 33 项原生检查，覆盖编辑器去掉标识后的正文回传、旧版误报重新检查、原个人富文本保留、PDF 原始批注评论更新、真正批注改动保护以及冲突读取提示。原生测试仅使用合成论文和笔记。

本版沿用 0.3.2 的 Windows 安装器集成及独立阅读补丁。PaperBridge 自有组件仍为手动更新。
