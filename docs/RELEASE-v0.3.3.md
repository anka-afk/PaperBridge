# PaperBridge 0.3.3

修复在 Zotero 编辑同步笔记后，整篇论文误报“原文批注（自动区被修改）”，导致个人正文和 AI 内容无法同步到 Obsidian 的问题。

Zotero 编辑器保存时会移除 HTML 注释，旧版用来标识批注的隐藏注释也会随之丢失。同步器之前把这个格式变化当成正文变化，现在比较时会忽略生成的标识注释，改从批注原文回链识别来源。

原文内容、用户修改和缺少的批注仍参与冲突检查，实际冲突不会被强制覆盖。

旧版已经暂停的记录会重新检查。只是隐藏标识变化的记录可以自动恢复；真正的双端修改、批注减少或正文改动仍会暂停并保留副本。不用删除冲突目录、重建笔记或手动指定覆盖来源。

读取有冲突的论文时，接口会提示 `note` 只是 Obsidian 副本，同时提供 Zotero 笔记副本，避免把一端为空误判成整份笔记为空。

## 升级

在 Zotero 插件管理器中从文件安装 `paperbridge-0.3.3.xpi`，然后重启 Zotero。Codex 官方侧栏、Reader Compatibility 和 Better Notes 都不用重装。

离开笔记编辑区，等后台同步运行后核对两端内容。如果还有实际冲突，先比较两端副本。

本版沿用 0.3.2 的 Windows 安装器和独立阅读补丁，PaperBridge 自有组件仍采用手动更新。
