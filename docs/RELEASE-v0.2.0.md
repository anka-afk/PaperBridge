# PaperBridge 0.2.0 — Windows 预发布

将 Zotero 阅读、Codex 问答、Obsidian 主笔记连接起来。每篇论文配对一份 Zotero 子笔记，支持小节级双向同步、独立修改合并、同小节冲突副本、三种阅读模板及分类。

适用于 Windows x64、Zotero 10（已在 10.0.6 验证），需要自行安装并登录 Codex 和 Obsidian。

下载 PaperBridge-Setup.exe 后选择本机路径，再按说明安装三个 Zotero 插件。已有 Codex 侧栏可保留。完整源码包可离线构建；SHA256SUMS.txt 用于核对下载文件。

验证：18 项 Node 自动测试通过；此前独立 Zotero 文库通过 16 项双向笔记实测，包括冲突、图片、公式、代码、双链及删除保护。第二台实体电脑迁移尚未验证。

限制：当前只支持个人文库、每篇论文一份主笔记；旧有其他笔记不自动合并。无跨电脑编辑锁，切换电脑前后请完成 Zotero 和知识库同步。尚未提供自动在线更新与代码签名。
