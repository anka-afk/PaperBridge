# PaperBridge 0.2.1

修复 Codex 桌面应用更新后删除旧版本目录，导致 Zotero 侧栏仍引用旧 `codex.exe`、提示“找不到 Codex CLI”的问题。

- 启动和后台检查时，如果旧路径失效，会在本机已知安装位置查找可用的 Codex 程序并更新侧栏配置。
- 手动指定的路径仍然有效时不会被改动。
- 路径恢复只修改本机程序路径，保留账号连接令牌、知识库路径和其他配置，修改前会备份原配置。
- 不依赖 Better Notes 加载成功，也不会重新登录、复制认证文件或重建论文笔记。

已有安装只需安装 `paperbridge-0.2.1.xpi` 并重启 Zotero。新的 Windows 安装包也包含这个修复。
