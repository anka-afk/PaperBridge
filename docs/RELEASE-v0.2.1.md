# PaperBridge 0.2.1 — Codex 更新后路径自动恢复

修复 Codex 桌面应用更新后删除旧版本目录，Zotero 侧栏仍引用旧 codex.exe、提示“找不到 Codex CLI”的问题。

- 启动及后台检查时，旧路径失效会在本机已知安装位置查找可用的 Codex 程序，并更新侧栏配置。
- 用户手动指定的路径仍有效时继续使用。恢复仅修改本机程序路径，保留账号连接令牌、知识库路径和其他配置，修改前备份原配置。
- 路径恢复不依赖 Better Notes 加载成功。不会重新登录、复制认证文件或重建论文笔记。

升级已有安装只需安装 paperbridge-0.2.1.xpi 并重启 Zotero。新的 Windows 安装包也包含此修正。
