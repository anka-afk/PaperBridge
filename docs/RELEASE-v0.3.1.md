# PaperBridge 0.3.1

修复首次迁移发生冲突后，后续同步可能重复追加空小节标题的问题。冲突记录不再被当成完整共同版本，未变化的冲突会持续暂停；解析时识别所有受管小节，并正确处理 Zotero 的嵌套笔记容器。历史空重复小节可以自动修复，所有非空内容保留；同一小节有多份非空正文时继续保留冲突。

批注改为读取 Zotero 数据库中已保存的记录，避免附件缓存暂时为空时生成“尚无批注”。已有批注标识减少时暂停覆盖，保留旧内容；确实删除批注时需要先核对删除情况。富文本或 Markdown 转换意外返回空内容时也暂停同步。

单篇论文暂停时，批量同步会报告该篇原因并继续处理其他论文，避免一处异常阻止整个文库更新。

批注区为空占位或经逐条核对是当前原始批注的子集时，可以补齐缺少的批注；存在正文改动、旧标识丢失或来源不明确时继续暂停。即使 Obsidian 批注区已经丢失，也不会用空来源继续清空 Zotero 中尚存的批注。

验证：35 项 Node 自动测试；独立 Zotero 10.0.6 / Better Notes 3.3.3 文库中通过 22 项检查，覆盖首次冲突后的多轮同步、输入改变、空重复标题修复、非空重复正文保护、嵌套容器、空转换、空缓存、批注补齐及两端原内容保留。

不会自动选择冲突来源、删除历史冲突副本或合并不明确的个人内容。已经产生的非空重复正文、Git 冲突标记或批注标识差异，需要比较两端副本并明确选择来源后再恢复。

## 下载与升级

- 已有用户：下载 `paperbridge-0.3.1.xpi`，在 Zotero 插件管理器中从文件安装并重启。其他插件和 API Key 无需重新配置。
- 新电脑：下载 `PaperBridge-Setup.exe`，选择本机知识库和 Codex 路径，再按 README 安装三个 Zotero 插件。
- 多电脑使用：先备份知识库和 Zotero 数据，将所有参与同步的电脑升级到 0.3.1 后，再继续双向同步，避免旧版继续写入异常。
- `PaperBridge-Source.zip` 包含源码、固定版本的构建依赖和第三方许可证。`SHA256SUMS.txt` 可用于核对安装包、源码包、插件及中文说明。

适用于 Windows x64、Zotero 10（已在 10.0.6 验证）。本次仍为预发布版本，尚未提供安装包代码签名和在线自动更新。论文、个人笔记、本机配置、API Key 和修复备份不随软件发布。
