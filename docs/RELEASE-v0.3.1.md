# PaperBridge 0.3.1

这版主要修复首次迁移冲突后的重复空小节，以及批注缓存和格式转换异常造成的误覆盖。

## 同步修复

- 冲突记录不再被当成完整的共同版本。未变化的冲突会持续暂停，不会重复追加空小节标题。
- 解析时会识别所有受管小节，并正确处理 Zotero 的嵌套笔记容器。历史空重复小节可以自动修复，非空内容都会保留；同一小节有多份非空正文时仍保留冲突。
- 批注改为读取 Zotero 数据库中已经保存的记录，避免附件缓存暂时为空时生成“尚无批注”。
- 批注标识减少、富文本或 Markdown 转换意外返回空内容时会暂停覆盖，保留旧内容。确实删除批注时，先核对删除情况再恢复。
- 单篇论文暂停时，批量同步会报告原因并继续处理其他论文，不再卡住整个文库。
- Obsidian 批注区为空，或逐条核对后确认是当前原始批注的子集时，可以补齐缺少的批注；正文改动、旧标识丢失或来源不明确时仍会暂停。

PaperBridge 不会自动选择冲突来源、删除历史冲突副本或合并不明确的个人内容。已经产生的非空重复正文、Git 冲突标记或批注标识差异，需要比较两端副本并选择来源后再恢复。

## 下载与升级

- 已有用户：安装 `paperbridge-0.3.1.xpi` 并重启 Zotero，其他插件和 API Key 不用重新配置。
- 新电脑：运行 `PaperBridge-Setup.exe`，选择本机知识库和 Codex 路径，再按 README 安装三个 Zotero 插件。
- 多电脑使用：先备份知识库和 Zotero 数据，将所有参与同步的电脑升级到 0.3.1，再继续双向同步。

`PaperBridge-Source.zip` 包含源码、固定版本构建依赖和第三方许可证，`SHA256SUMS.txt` 可以用来核对下载文件。

适用于 Windows x64、Zotero 10（已在 10.0.6 验证）。本次仍为预发布版本，尚未提供安装包代码签名和在线自动更新。
