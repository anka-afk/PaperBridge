# PaperBridge 0.3.4

这版修了两个问题：批注内容没变、ID 变了时同步误暂停；同步暂停后，Codex 只读到旧的 Obsidian 副本，误以为个人笔记为空。

## 批注 ID 变化后重新配对

以前只要旧批注 ID 不在当前 PDF 中，同步器就会暂停整篇论文。现在只有批注正文、评论、页码和 PDF 来源全部一致，而且两端能唯一对应时，才会更新回链中的批注 ID。

新增批注会正常加入。批注减少、内容不同或无法唯一匹配时仍会暂停，不会仅凭数量相同就覆盖。

Zotero 富文本的自动批注区也使用这套规则。个人笔记和 AI 整理仍按小节检查冲突；没有共同同步历史，或同一小节在两端同时修改时，会保留两端副本，等你选择来源。旧版留下的暂停和冲突记录会重新检查，不用删除同步状态或保护标记。

## 同步暂停时也能读取 Zotero 笔记

`get_current_paper` 和 `get_paper` 现在都会提供配对 `zoteroNote` 的当前正文，`note` 仍表示 Obsidian 文件。

暂停或冲突时，接口会返回 `noteReadWarning`，提醒调用方比较两端。同步尚未完成或 Obsidian 文件缺失时，也能读取 Zotero 中已经保存的笔记。返回前会检查笔记是否属于当前论文、是否已被删除。

## 升级

在 Zotero 插件管理器中从文件安装 `paperbridge-0.3.4.xpi`，然后重启 Zotero。Better Notes、Codex 官方侧栏和阅读兼容补丁都不用重装。
