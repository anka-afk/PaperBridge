# PaperBridge 0.3.4

修复批注 ID 改变后笔记同步误暂停，以及 Codex 因只读取旧 Obsidian 副本而误判个人笔记为空的问题。

## 批注重新配对

原同步器发现任意旧批注 ID 不在当前 PDF 中，就立即暂停整个论文的同步。现在仅在批注正文、评论、页码和 PDF 来源全部一致，且两端内容能唯一对应时，更新生成回链中的批注 ID。新增批注可以正常加入；批注减少、无法唯一匹配或内容不同仍暂停，不会据相同数量推定安全。

Zotero 富文本自动批注区采用相同的匹配规则。个人笔记与 AI 整理仍使用原来的逐小节冲突检查。没有共同同步历史或同一小节在两端同时修改时，继续保留两端副本，等待用户明确选择来源。旧版暂停与冲突记录会重新检查，无需删除同步状态或保护标记。

## 读取笔记

`get_current_paper` 和 `get_paper` 始终提供配对的 `zoteroNote` 当前正文，`note` 仍表示 Obsidian 文件。暂停和冲突状态都返回 `noteReadWarning`，提醒调用方比较两端；同步未完成或 Obsidian 文件缺失时，也能读取 Zotero 中已保存的笔记。返回前验证笔记属于当前论文且未被删除。

## 升级

在 Zotero 插件管理器中从文件安装 `paperbridge-0.3.4.xpi`，然后重启 Zotero。Better Notes、Codex 官方侧栏和阅读兼容补丁无需重装。

## 验证

- 52 项 Node 自动测试，覆盖唯一 ID 配对、重复内容、真实删除、正文/评论/页码/PDF 来源差异、个人区域保留、暂停读取以及原有同步与传输功能。
- 独立 Zotero 文库与真实 Better Notes 转换验证：相同批注重建后恢复同步并更新两端回链，同时回传 Zotero 个人编辑、逐字保留个人富文本；实际批注区改动继续保留冲突。

原生测试只使用合成论文与笔记，不操作用户文库。
