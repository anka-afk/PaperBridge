# PaperBridge Reader Compatibility 0.1.0

独立的 Zotero 10 阅读选区兼容插件。与 Codex for Zotero 同时启用，支持 HTML 选中即问，保留弹窗关闭后的当前选区。

## 安装

1. 在 Zotero 的“工具 → 插件”打开插件管理器，齿轮菜单选择从文件安装插件，选择 `paperbridge-reader-compat-0.1.0.xpi`。
2. 如果先前使用 PaperBridge 定制侧栏 `2026.299.1.1` 或 `2026.299.1.2`，再从文件安装官方侧栏原包：安装目录中名为 `codex-for-zotero.xpi`，单独下载时名为 `codex-for-zotero-official.xpi`。无需卸载侧栏或删除设置。
3. 重启 Zotero，打开“工具 → 阅读兼容补丁状态…”，应显示“选区兼容补丁已启用”及侧栏版本。
4. 打开论文的 HTML 阅读页，划选一段文字，在 Codex 侧栏输入问题。单段当前选区不需要点 Add；需要固定保留多段时仍可用 Add。

## 更新与停用

兼容插件仅在内存中挂接方法，不修改官方 XPI、官方更新地址或账号配置。官方侧栏的插件 ID 保持不变；官方更新替换侧栏实例后，兼容插件会检测并重新挂接。安装独立补丁本身不会恢复旧定制侧栏里被禁用的官方更新地址，需要完成上面的第 2 步。

这仍依赖侧栏内部接口，无法保证兼容未来所有版本。检测到接口变化时停止挂接，并在状态菜单显示原因；如果更新后不能捕获选区，请先检查这里。当前兼容插件自身采用手动更新，没有配置在线更新服务。它不控制 Zotero 或官方侧栏的更新服务。

停用兼容插件会恢复它包装的方法；已打开的阅读页建议关闭后重新打开，让原侧栏重新建立选区监听。它不读写 Obsidian 笔记、Zotero 文献数据、Codex 登录或 API Key。

## 验证范围

- Node 回归覆盖 HTML 阅读上下文、PDF 不受影响、选区保留、停用恢复、侧栏替换后重挂接和连续后台检查。
- 独立 Zotero 10.0.6 测试文库使用未修改的官方 Codex for Zotero 2026.299.1：真实鼠标划选 HTML，不点 Add，检查选区和请求上下文构建结果；关闭弹窗后保留，重新选择后替换。重新安装官方包后可重挂接。
- 原生测试使用合成论文，不登录账号、不发送模型请求。对未来官方版本只提供运行时接口检测，不视为已经逐版本验证。

## 构建

在源码仓库根目录运行 `python reader_compat.py --output dist`，只打包此插件；`python build.py` 构建完整 Windows 安装包。测试命令为 `node --test tests/reader-compat.test.cjs`。
